What each part of Harbor does

Local AI

Runs a language model on this PC instead of in the cloud. Wave OS uses it as a fallback when Theta EdgeCloud has no worker free, so answers keep coming when the network is busy.

Harbor finds whatever you already have running — Ollama, LM Studio, Jan, llama.cpp, vLLM or text-generation-webui — because they all speak the same API. The card names the one it found.

You do not need this. Wave OS works fine without it — it is a speed and privacy option, not a requirement. Harbor can start and stop Ollama; anything else it can only use, so close those in their own app.

Cloudflare Tunnel

Gives your local AI a public address so Wave OS in the cloud can reach it. This is the tunnel for Ollama only.

Separate from Remote access below, which has its own tunnel for files. Turning this on does not share any files.

Wave OS Pairing

Connects this PC to your Wave OS account so it shows up as one of your devices. You do this once, with a six-digit code.

This is the only code most people ever need.

Shared folders

The folders this PC will let your other devices see. Nothing outside this list is ever reachable from the cloud, and everything in it is read-only.

Empty list means nothing is shared, even with Remote access on.

Remote access

Lets your phone and your other devices reach the shared folders, by giving this PC a temporary public address. Off means files never leave this machine.

Only the shared folders are reachable this way — never the whole drive.

File server

The small server inside Harbor that actually reads files off the disk. It listens on this PC only, at an address nothing outside can dial.

Nothing to configure. The eye icon hides the address for screen sharing.

Browser access — and when to ignore it

When you open Wave OS inside Harbor, it can already read every file on this PC. That is automatic and needs no code.

A normal browser — Chrome or Edge — cannot, because Harbor has no way to know it is really you rather than a random website. So a browser gets access only if you click here for a code and type it into Wave OS. It lasts 8 hours, covers that one browser, and disappears when Harbor quits.

If you use Wave OS inside Harbor and on your phone, you never need this. It exists for shared and lab computers, where each person should get their own temporary access instead of a permanent one.

Allowed browsers

How many browsers currently hold that temporary access, and when the first one runs out. Click it to revoke all of them immediately.

Quitting Harbor also revokes every one.
